
**选择正确的 Profile** 我们需要一个支持桌面和 OpenRC 的 Profile。


```bash
eselect profile list
# 选择类似 default/linux/amd64/23.0/desktop 的编号 (不要选 systemd 版本)
eselect profile set <对应的编号>
emerge -avuDN @world

配置与编译新内核
进入源码目录。为了节省时间，可以直接复用当前正在运行内核的配置：

Bash
cd /usr/src/linux
zcat /proc/config.gz > .config  # 或者 cp ../linux-旧版本/.config .
更新配置文件以适应新内核（遇到新选项时按回车使用默认值即可）：

Bash
make olddefconfig
如果你想做进一步的裁剪或开启特定的硬件支持：

Bash
make menuconfig

VMware 与 Wayland 必备的内核选项：
Device Drivers -> Graphics support -> Direct Rendering Manager (DRM) -> DRM_VMWGFX (设为 * 或 M)
Device Drivers -> Network device support -> VMXNET3 (设为 * 或 M)
Device Drivers -> Misc devices -> VMware Balloon Driver (设为 * 或 M)
Device Drivers -> Input device support -> Event interface (设为 *)

make -j$(nproc)
make modules_install
make install
```

让引导程序（以 GRUB 为例）发现新内核：

Bash

```
grub-mkconfig -o /boot/grub/grub.cfg
```

Gentoo 提供了一个专门清理旧内核的工具，非常安全且高效：

Bash

```
emerge app-admin/eclean-kernel
# 保留当前正在运行的内核，删除其余所有旧内核
eclean-kernel -n 1
grub-mkconfig -o /boot/grub/grub.cfg
```

**1. 安装基础工具与配置服务**

Bash

```
emerge --ask app-admin/sysklogd sys-process/cronie net-misc/networkmanager sys-fs/dosfstools
rc-update add sysklogd default
rc-update add cronie default
rc-update add NetworkManager default
rc-update add dbus default
rc-update add elogind default # Wayland 强依赖
```

**2. 完美安装 open-vm-tools** 按照你之前验证过的 USE 标志，将配置写入 `package.use`：

Bash

```
mkdir -p /etc/portage/package.use
echo "app-emulation/open-vm-tools X deploypkg dnet fuse icu pam resolutionkms ssl vgauth gtkmm multimon" >> /etc/portage/package.use/vmware
emerge --ask app-emulation/open-vm-tools
rc-update add vmware-tools default
```


### GLIBC

之前我们用 `package.mask` 屏蔽了 Glibc 的降级。这在 Gentoo 中是正常的做法（特别是使用二进制仓库时，仓库版本往往落后于 Portage 树）。

- 你可以一直留着那个 mask。
    
- 等到几周后，如果你运行 `emerge --sync` 发现二进制仓库更新了，再删掉 `/etc/portage/package.mask/glibc` 尝试升级。
